Tecnica: Comparação-troca
Algoritmo: Ordenação por seleção direta
Autores:
Data:
Conceitos: invariante, complexidade, vetor
Problema: Ordenar um vetor escolhendo, a cada passo, o menor elemento ainda não posicionado e colocando-o na primeira posição livre.

Ideia. Dividimos o vetor em duas partes: o prefixo v[0..i-1], já ordenado e definitivo, e o sufixo v[i..n-1], ainda desordenado. Em cada passo, procuramos o menor elemento do sufixo (seleção) e o trocamos com v[i]; assim o prefixo ordenado cresce uma posição.

Invariante. No início da iteração i: (a) v[0..i-1] está em ordem crescente; (b) todo elemento de v[0..i-1] é menor ou igual a todo elemento de v[i..n-1]. A troca de v[i] com o mínimo m do sufixo preserva (a) e (b) com i+1 no lugar de i. Quando i chega a n-1, o sufixo tem um só elemento, que por (b) é o maior; portanto o vetor inteiro está ordenado. É por isso que o laço externo vai só até n-2.

Complexidade. A busca do mínimo em v[i..n-1] faz n-1-i comparações, de modo que o total é (n-1) + (n-2) + ... + 1 = n(n-1)/2 = Θ(n²) comparações em todos os casos, mesmo com o vetor já ordenado. Em compensação, faz no máximo n-1 trocas, o que é vantajoso quando mover elementos é caro. O espaço extra é O(1). Na forma com troca à distância, o método não é estável (por exemplo, ao ordenar {2a, 2b, 1}, a troca de 2a com 1 faz 2a passar para depois de 2b).

<<C
#include <stdio.h>

void selecaoDireta(int v[], int n)
{
    for (int i = 0; i < n - 1; i++) {
        /* invariante: v[0..i-1] ordenado e <= v[i..n-1] */
        int m = i;                       /* índice do menor de v[i..n-1] */
        for (int j = i + 1; j < n; j++)
            if (v[j] < v[m])
                m = j;
        if (m != i) {
            int t = v[i];
            v[i] = v[m];
            v[m] = t;
        }
    }
}

int main(void)
{
    int v[] = {64, 25, 12, 22, 11};
    int n = sizeof v / sizeof v[0];

    selecaoDireta(v, n);
    for (int i = 0; i < n; i++)
        printf("%d ", v[i]);             /* 11 12 22 25 64 */
    printf("\n");
    return 0;
}
