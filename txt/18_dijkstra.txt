Tecnica: Método guloso
Algoritmo: Dijkstra (distância mínima)
Autores: Edsger W. Dijkstra
Data: 1956 (concepção); 1959 (publicação)
Conceitos: grafo, caminho mínimo, fila de prioridade, método guloso
Problema: Dado um grafo (orientado ou não) com custos não negativos nas arestas e um vértice de origem s, calcular a menor distância de s a cada um dos demais vértices e um caminho que a realize.

Ideia gulosa. O algoritmo mantém, para cada vértice v, uma estimativa d[v] do custo do melhor caminho conhecido de s até v (inicialmente 0 para s e infinito para os demais) e o conjunto S dos vértices cuja distância já é definitiva. A cada passo: (1) escolhe-se o vértice u fora de S com menor d[u] e ele passa para S; (2) "relaxam-se" as arestas que saem de u: para cada aresta (u, v) de custo c, se d[u] + c < d[v], então d[v] recebe d[u] + c e pai[v] = u. É um [[metodo_guloso]]: a escolha do vértice de menor estimativa nunca é revista.

Invariante e prova curta. Vale em todo passo: (a) para todo v em S, d[v] é a distância mínima de s a v; (b) para todo v fora de S, d[v] é o custo do melhor caminho de s a v que usa apenas vértices de S como intermediários. Seja u o vértice escolhido. Se houvesse um caminho de s a u mais curto que d[u], ele sairia de S por alguma aresta (x, y) com y fora de S; então d[y] ≤ custo do trecho até y ≤ custo do caminho todo < d[u], contrariando a escolha de u como o de menor d fora de S. Esse argumento usa custos não negativos: com arestas negativas o algoritmo pode errar (use Bellman-Ford). Ao fim, S contém todos os vértices alcançáveis e d[v] é infinito para os demais.

Complexidade. Na versão do código abaixo (matriz de adjacência, busca linear do mínimo) são n escolhas, cada uma custando O(n), mais n relaxamentos por vértice: Θ(n²). Com listas de vizinhos e uma fila de prioridade, implementada como monte binário (veja [[ordena_monte]]), o custo cai para O((n + m) log n), vantajoso em grafos esparsos. Em grafos sem pesos, a [[busca_largura]] resolve o problema em Θ(n + m).

Sobre as datas. Dijkstra concebeu o algoritmo em 1956, segundo seu próprio relato, em cerca de vinte minutos, sem lápis e papel, e só o publicou em 1959, na nota "A note on two problems in connexion with graphs" (Numerische Mathematik, v. 1, p. 269-271; recebida em 11 de junho de 1959). Essa nota trata de dois problemas: a árvore de comprimento total mínimo (que se relaciona com [[kruskal]]) e o caminho mais curto entre dois nós dados. Por isso o ano costuma aparecer ora como 1956, ora como 1959.

<<C
#include <stdio.h>

#define MAXV 20
#define INF 1000000000                   /* "infinito": maior que qualquer distância */

/* g[u][v] = custo da aresta u->v, ou INF se não existe. */
void dijkstra(int n, int g[][MAXV], int s, int d[], int pai[])
{
    int fechado[MAXV] = {0};             /* fechado[v] == 1 <=> v em S */

    for (int v = 0; v < n; v++) {
        d[v] = INF;
        pai[v] = -1;
    }
    d[s] = 0;
    for (int passo = 0; passo < n; passo++) {
        int u = -1;
        for (int v = 0; v < n; v++)      /* menor d entre os abertos */
            if (!fechado[v] && (u == -1 || d[v] < d[u]))
                u = v;
        if (d[u] == INF)
            break;                       /* o resto é inalcançável */
        fechado[u] = 1;
        for (int v = 0; v < n; v++)      /* relaxa as arestas que saem de u */
            if (g[u][v] != INF && d[u] + g[u][v] < d[v]) {
                d[v] = d[u] + g[u][v];
                pai[v] = u;
            }
    }
}

static void imprimeCaminho(const int pai[], int v)
{
    if (pai[v] != -1)
        imprimeCaminho(pai, pai[v]);
    printf("%d ", v);
}

int main(void)
{
    int n = 5;
    int g[MAXV][MAXV];

    for (int i = 0; i < n; i++)
        for (int j = 0; j < n; j++)
            g[i][j] = INF;
    g[0][1] = 10; g[0][3] = 5;
    g[1][2] = 1;  g[1][3] = 2;
    g[2][4] = 4;
    g[3][1] = 3;  g[3][2] = 9; g[3][4] = 2;
    g[4][0] = 7;  g[4][2] = 6;

    int d[MAXV], pai[MAXV];
    dijkstra(n, g, 0, d, pai);
    for (int v = 0; v < n; v++) {
        printf("d[%d] = %d  caminho: ", v, d[v]);
        imprimeCaminho(pai, v);
        printf("\n");
    }
    /* d = 0 8 9 5 7 ; caminho até 2: 0 3 1 2 */
    return 0;
}
C>>
